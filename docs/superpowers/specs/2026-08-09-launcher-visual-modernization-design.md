# 开放启动器视觉现代化设计规格

## 目标

把开放启动器升级为更精致、更易读的中文车机桌面：保留模块化仪表盘能力，加入三套明确风格的主题、可覆盖配色、统一圆角规范，并清理全部用户可见英文。

## 主题

### 精致 OEM

深灰背景、柔和卡片层级、8–12dp 圆角、低亮度边框和轻微阴影。默认强调色为冰蓝，重点是驾驶时的可读性。

### 赛博科技

更高亮的青蓝/紫色强调色、12–16dp 圆角、轻微发光边框和短时过渡动效。避免持续粒子和强闪烁。

### 极简玻璃

半透明卡片、16dp 圆角、柔和阴影和弱边框。使用统一透明度，避免组件互相遮挡。

## 颜色覆盖

主题提供默认颜色；用户可以覆盖强调色、背景色、卡片色、浮层色、文字色和边框色。恢复默认只清除覆盖值，不改变布局或权限设置。所有颜色通过 `ThemeColors` 统一进入 Compose MaterialTheme，页面组件不再散落主题常量。

## 形状规范

- 普通卡片 12dp
- 大型组件 16dp
- 输入框和按钮 10dp
- 小型标签 8dp
- 弹窗 20dp
- 底部导航 18dp

## 动效

主题切换使用 420ms 颜色过渡；指南针使用 420ms 平滑旋转；页面使用短距离淡入滑动；组件拖动显示吸附占位。动效只服务于状态变化，不添加持续装饰动画。

## 汉化边界

用户可见标题、按钮、空状态、错误提示、权限说明、无障碍描述全部使用中文。组件 ID、包名、API 字段、日志 Tag、协议值、单位和媒体元数据保持原样。

## 验收标准

1. 三套主题均能在设置页切换并持久化。
2. 主题切换会同步改变背景、卡片、边框、强调色和按钮状态。
3. 主屏、设置页、应用库、组件库、弹窗和侧边栏不再使用直角主容器。
4. 用户可见英文扫描结果只剩技术字段、应用自身名称或媒体元数据。
5. Release APK 构建成功、签名验证通过并复制到桌面。
